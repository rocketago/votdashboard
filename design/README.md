# Design handoff bundle

The source material this app was built from, kept for provenance.

- `vot-targets.html` — the Claude Design prototype, a single self-contained file. This
  is the visual spec; `src/styles/app.css` is transcribed from its stylesheet.
- `chats/chat1.md` — the full design conversation. Worth reading before changing
  anything visual: it records what was asked for, what the design assistant guessed at,
  and what it flagged as needing real data.
- `*.png` — screenshots captured during the design session. Several are from earlier
  iterations (elected-office filters, "Coordinated Ops 2026 Cycle" header) that were
  later removed, so treat the HTML as authoritative where they disagree.

Nothing here is built or served. It is reference only.
